# Phase 9.1–9.3 — Atlas Intelligence Foundation

This release adds a plugin-oriented intelligence layer without enabling live order submission.

## Included

- Deterministic OHLCV feature engineering
- Leakage-safe technical feature matrix
- Time-series cross-validation
- Logistic-regression and random-forest trainers
- Feature importance
- Versioned model artifact persistence
- Rich market-regime classification
- Equal, inverse-volatility, and risk-parity allocation
- Position caps, cash reserve, and volatility targeting

## Safety boundary

All generated models and allocations are research outputs. They are not wired to a live broker.
UTC remains the persistence standard; exchange-session presentation remains America/New_York.
