# Phase 13.1–13.3: Alpha Generation and Execution Intelligence

Version 4.3.3 adds four paper-first research modules:

- `src.alpha_engine`: normalized, horizon-aware alpha factors and cross-sectional ranking.
- `src.microstructure`: spread, liquidity, participation, and expected-slippage gating.
- `src.paper_analytics`: signal/order/fill/close lifecycle analytics.
- `src.research_journal`: append-only experiment audit trail.

No module submits broker orders. Live execution remains disabled by default.
